## 🔤 PELAJARAN OPERATOR CF (mahal, jangan diulang)

| Operator | Plan Bos |
|---|---|
| `starts_with`, `ends_with`, `eq`, `and`, `or`, `not` | ✅ BISA |
| `contains()` | ❌ Enterprise-only (error `20127`) |
| `matches()` regex | ❌ TIDAK ADA |

- **`== false` DITOLAK** → pakai `not starts_with(...)`
- **Jangan kirim `cache_key`** — `cookie` bukan field top-level & tidak didukung plan Bos
- **`404` payload `override_origin`** → CF mengabaikan `Cache-Control: private` aplikasi (dua lapis aman, tidak melawan)
- **Pesan error `20127` WAJIB dibaca UTUH** — memuat posisi caret; kalau dipotong jadi menebak
- **DELETE ruleset sering balas non-200 walau terhapus** → verifikasi ulang dengan GET

## 🧱 PERUBAHAN KODE (`app/main.py`)

1. **Guard kondisional di `oo_aset()`** — aset mesin tanpa login, dokumen user wajib:
   ```python
   STATIS = ('/sdkjs/', '/web-apps/', '/sdkjs-plugins/', '/fonts/',
             '/themes.json', '/plugins.json')
   if not any(p in '/' + sisa for p in STATIS):
       with SessionLocal() as _db:
           if not user_dari_request(req, _db):
               raise HTTPException(303, headers={'Location': '/masuk'})
   ```
2. **Header cache dua tingkat:**
   - aset mesin → `private, max-age=31536000, immutable` + `X-Eduai-Boleh-Edge: 1`
   - dokumen/lain → `private, no-store` + `X-Eduai-Boleh-Edge: 0`
3. ⚠️ `wajib_login()` **tidak bisa** dipanggil manual (butuh `db` yang disuntik FastAPI) → pakai `user_dari_request(req, db)` langsung.

**Skrip idempotent:** `scripts/pasang_cache_final.py` (aman dijalankan berulang).

### 🚨 DUA BAHAYA yang HARUS dicegah

**Bahaya 1 — Dokumen mahasiswa tersimpan di server Cloudflare.**
Kalau `/cache/files/*` ikut di-cache publik → naskah tesis/artikel mahasiswa
berada di server pihak ketiga. Melanggar janji "data 100% di VPS Bos".

**Bahaya 2 — Aset editor di-cache publik padahal butuh login.**
Guard `/oo/aset` mewajibkan login. Kalau di-cache `public`, orang **belum login**
bisa ambil dari cache CF → tembus guard.

### ✅ Cara mencegah (WAJIB sebelum pasang Cache Rule)

**Langkah 1 — Ubah kode: tandai aset statis dengan header KHUSUS**

`app/main.py` fungsi `oo_aset()`:
```python
# aset statis OO (mesin + UI) -> boleh cache EDGE, tapi tetap wajib login
STATIS = ('/sdkjs/', '/web-apps/', '/sdkjs-plugins/', '/themes.json',
          '/plugins.json', '/fonts/')
if any(p in url for p in STATIS):
    hdr['Cache-Control'] = 'private, max-age=31536000, immutable'
    hdr['X-Eduai-Cacheable'] = '1'      # penanda untuk Cache Rule CF
else:
    hdr['Cache-Control'] = 'private, no-store'   # dokumen user: JANGAN cache
    hdr['X-Eduai-Cacheable'] = '0'
```

**Langkah 2 — Cache Rule CF hanya untuk aset statis**

Rule CF: cache HANYA kalau `http.request.uri.path` cocok
`/(sdkjs|web-apps|sdkjs-plugins)/` ATAU berakhiran `themes.json`/`plugins.json`,
**DAN BUKAN** `starts_with(path, "/oo/aset/cache/files/")`.

**Langkah 3 — Jaga guard tetap bekerja**

Karena aset butuh login, cache CF **harus** menghormati cookie:
`Cache Rule` dengan `cache_key` yang menyertakan cookie sesi, ATAU
tambahkan `Vary: Cookie` (sudah ada di kode ✅).

> ⚠️ Kalau `Vary: Cookie` dipakai, CF tidak akan berbagi cache antar user
> (setiap user punya cache sendiri) → **kurang optimal**. Alternatif: naikkan
> jadi cache publik TAPI guard dipindah ke tingkat CF (Cloudflare Access),
> bukan di aplikasi. **Ini keputusan desain yang perlu ACC Bos.**

## 📊 DUA PILIHAN ARSITEKTUR (Bos pilih)

### Pilihan 1 — Aman, cache per-user (efek terbatas)
- Aset tetap butuh login.
- CF cache per-cookie → tiap user punya cache sendiri.
- **Efek:** kunjungan kedua user yang SAMA jadi cepat. User baru/ganti HP tetap unduh.
- **Risiko:** 🟢 Rendah. Tidak ada dokumen/user lain yang bocor.
- **Perbaikan:** ~50% dari manfaat.

### Pilihan 2 — Optimal, cache bersama (seperti Google Docs)
- Aset di-cache **publik** di CF (tanpa cookie).
- Guard editor dipindah: dokumen user tetap wajib login, **aset mesin tidak**.
- **Efek:** SEMUA user ambil dari CF terdekat. Kunjungan pertama pun cepat.
- **Risiko:** 🟡 Sedang — perlu pastikan **tidak ada data user** yang bocor.
  Aman, karena `/sdkjs/*` & `/web-apps/*` adalah file OO statis (sama untuk semua user).
- **Perbaikan:** ~100% dari manfaat = setara Google Docs.

**Wulan sarankan Pilihan 2**, dengan syarat uji ketat di bawah.
