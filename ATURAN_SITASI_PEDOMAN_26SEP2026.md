## 7.1 PERUJUKAN (SITASI) — di dalam teks

```
BENTUK DASAR : nama akhir + tahun, DI ANTARA TANDA KURUNG
2 PENULIS    : sebut nama akhir KEDUA penulis
>2 PENULIS   : nama pertama + dkk (et al.)
TANPA PENULIS: nama LEMBAGA penerbit / nama dokumen / nama koran
TERJEMAHAN   : nama penulis ASLINYA
2+ SUMBER    : satu tanda kurung, dipisah TITIK KOMA (;)
```

## 7.2 KUTIPAN LANGSUNG

### ▸ Kurang dari 40 kata (§7.2.1)
```
Ditulis DI ANTARA tanda kutip ("...") → TERPADU dalam teks utama
Diikuti: nama penulis + tahun + NOMOR HALAMAN

DUA cara:
  (a) penulis disebut dalam teks:
      Kamaludin et al., (2012:156) menyimpulkan "ada hubungan…"
  (b) penulis bersama tahun & halaman dalam kurung:
      …adalah "ada hubungan…" (Kamaludin et al., 2015:156).
```

### ▸ 40 kata atau lebih (§7.2.2) — **KUTIPAN BLOK**
```
🚨 TANPA tanda kutip
🚨 TERPISAH dari teks yang mendahului
🚨 Ditulis 1,2 cm dari garis tepi KIRI dan KANAN  (menjorok dua sisi)
🚨 Diketik dengan SPASI TUNGGAL (bukan 1,5)
🚨 Nomor halaman WAJIB ditulis

Bila di dalam kutipan ada paragraf baru lagi:
  baris barunya dimulai 1,2 cm dari tepi kiri garis teks kutipan
```

### ▸ Kutipan sebagian dihilangkan (§7.2.3)
```
Kata-kata/kalimat yang dibuang → diganti TIGA TITIK (…)
Contoh: "Hasil pengujian … menunjukkan hasil yang konsisten…"
```

## 7.3 KUTIPAN TIDAK LANGSUNG (parafrase)
```
Ditulis TANPA tanda kutip, TERPADU dalam teks, bahasa penulis sendiri
Nama penulis boleh disebut dalam teks ATAU dalam kurung bersama tahun
SANGAT DIANJURKAN menyebutkan NOMOR HALAMAN

Contoh (penulis dalam teks):
  Seperti yang dikatakan oleh Alfansi (2014: 4) bahwa pada dekade 1990-an…

Contoh (penulis dalam kurung):
  …fenomena bearish dan bullish di pasar modal Indonesia (Usman, 2012:9).

Contoh lembaga tanpa penulis:
  Badan Pemeriksa Keuangan (BPK) memastikan bahwa … (Kompas, Rabu 24 Maret 2012).
```

## 7.4 DAFTAR PUSTAKA — aturan umum

```
ISI: HANYA bahan yang DIKUTIP (langsung/tak langsung).
     Bahan yang dibaca tapi TIDAK dikutip → TIDAK dicantumkan.

URUTAN UNSUR:
  (1) nama penulis — urutan: NAMA AKHIR, nama awal, nama tengah,
      TANPA gelar akademik
  (2) tahun penerbitan
  (3) judul, termasuk anak judul (subjudul)
  (4) kota tempat penerbitan
  (5) nama penerbit

Nama >1 penulis : sama seperti penulis pertama
Nama 2 bagian   : nama akhir + KOMA + nama awal (boleh disingkat,
                  tapi HARUS KONSISTEN dalam satu karya ilmiah) + titik
Penulis TIM     : SEMUA nama dicantumkan

✅ Style yang dipakai: **APA** (pedoman menyebut "dapat menggunakan style APA")
```
