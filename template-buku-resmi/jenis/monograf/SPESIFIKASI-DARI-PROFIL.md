## Format

| Item | Nilai |
|---|---|
| Ukuran | A5 — 14.8 × 21.0 cm (8391 × 11906 twip) |
| Margin (twip) | atas 1134 · bawah 1134 · kiri 1134 · kanan 1134 |
| Gutter (twip) | — (MENUNGGU KEPUTUSAN) |
| Area teks (twip) | 6123 |
| Font isi | Cambria 11 pt (`w:sz` 22) |
| Font judul bab | Cambria 14 pt (`w:sz` 28) |
| Spasi baris | kelipatan 1.15 (line 276) |
| Target halaman | 150–180 halaman |
| Target bab | 8 (rentang 5-8) |

## Unsur wajib

- pernyataan_novelty
- kebaruan_tegas_di_bab4_atau_bab5
- keterbatasan_penelitian
- daftar_pustaka_apa7_indentasi_gantung
- sitasi_terverifikasi_tidak_mengarang
- struktur_buku_utuh: sampul, hak cipta, prakata, daftar isi, bab 1-5, daftar pustaka, tentang penulis

## Aturan tulisan

- Tone: akademik formal — orang ketiga, tanpa sapaan 'Anda', istilah teknis dipakai konsisten, kalimat lugas
- Sitasi: terverifikasi, dilarang mengarang (skill buku-monograf)
- Larangan teks: larangan budaya berlaku untuk teks (daftar kata: brief_visual KATA_* / mutu-buku/gambar-dan-visual/prompt/larangan-budaya.md)
